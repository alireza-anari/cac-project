- **Lane 2 — P0 BLOCKED / NOT_RUN:** real irreversible W commitment/high-watermark under its **own** snapshot rollback, rebootstrap, root/key-policy restoration and signer retirement; protected verifier policy, physical same-identity actor clone, real network split-brain, independent host/administration/key custody, HA/PITR and production authentication. A fourth PostgreSQL database on the same CI host is not a trustworthy Production anti-rollback root. Declared loss-of-continuity test shows denial given a flag, not detection of real W rollback.
- **Lane 3 — P0 BLOCKED / NOT_RUN:** there is **no approved safe resolution/clearing of orphan OPEN**, manual or automatic. UNKNOWN persists; preventing successor READY can cause indefinite **safe unavailability**. Missing-session or timeout assumptions never justify authority revival.
- **Follow-up focused proof gaps — NOT_RUN:** separately named **pre-ABORT crash cut** and **lost ABORT/CLOSE acknowledgment wire schedules**; physical standby/partition/power-loss, general transaction interleavings and operational DR also not covered. These gaps do not invalidate the recorded **bounded** F cases, but bar blanket lifecycle-completeness claims.
- **P1 constrained:** trusted fixture controller/coordinator/host and admission system, bounded SQL catalog checks, bounded crash/race schedules, single-host failure domain and availability cost. Superuser/host compromise is explicitly excluded. Synthetic W wire format, key custody and TTL are not approved interfaces.
